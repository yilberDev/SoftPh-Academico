# RF-019 — Invitación y activación de cuenta del residente

> Transcripción de la Tabla 38 del documento académico (*PROYECTO DE GRADO*). El documento original no se modifica.

| Campo | Valor |
|---|---|
| Requerimiento funcional N° | RF-019 |
| Nombre | Invitación y activación de cuenta del residente |
| Tipo | Funcional |
| Prioridad | Alta |
| Actor | Administrador / Residente |
| Descripción | El sistema debe permitir que el residente complete la activación de su cuenta mediante una invitación previamente generada por el administrador, verificando la validez de la invitación y asociando la cuenta con la unidad residencial correspondiente. |
