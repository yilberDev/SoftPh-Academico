# Requisitos funcionales (RF-001 a RF-019)

Transcripción desde el documento académico aprobado, un archivo por identificador (p. ej., `RF-001.md`).

El documento académico original no se modifica. Cualquier diferencia de diseño se registra en [../extensiones-diseno.md](../extensiones-diseno.md).
