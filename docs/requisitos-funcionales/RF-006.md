# RF-006 — Visualización de residentes registrados

> Transcripción de la Tabla 25 del documento académico (*PROYECTO DE GRADO*). El documento original no se modifica.

| Campo | Valor |
|---|---|
| Requerimiento funcional N° | RF-006 |
| Nombre | Visualización de residentes registrados |
| Tipo | Funcional |
| Prioridad | Alta |
| Actor | Administrador |
| Descripción | El sistema debe permitir al administrador consultar la información de los residentes registrados y visualizar los datos asociados a cada uno dentro de la propiedad. |

## Trazabilidad

- Historia de usuario: [HU-006](../historias-usuario/HU-006.md)
- Caso de uso: [CU-006](../casos-uso/CU-006.md)
- Módulo (matriz de trazabilidad): Gestión de residentes

## Cobertura en la implementación

- Listado paginado de los residentes registrados.
- Búsqueda por nombre o número de documento.
- Filtro por estado (activo o inactivo).
- Ordenamiento por las columnas permitidas (nombre, documento, unidad, teléfono, correo y estado).
- Consulta restringida al administrador mediante el control de acceso por rol (HU-018).
- La confirmación de la actualización de datos queda pendiente de la HU de edición del residente (HU-015).
