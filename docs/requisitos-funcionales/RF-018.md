# RF-018 — Control de acceso según el rol

> Transcripción de la Tabla 37 del documento académico (*PROYECTO DE GRADO*). El documento original no se modifica.

| Campo | Valor |
|---|---|
| Requerimiento funcional N° | RF-018 |
| Nombre | Control de acceso según el rol |
| Tipo | Funcional |
| Prioridad | Alta |
| Actor | Administrador / Residente |
| Descripción | El sistema debe controlar el acceso a las funcionalidades de acuerdo con el rol asignado al usuario, permitiendo únicamente las operaciones correspondientes a sus permisos. |
