# RF-003 — Registro de residente mediante invitación

|---|---|
| Requerimiento funcional N° | RF-003 |
| Nombre | Registro de residente mediante invitación |
| Tipo | Funcional |
| Prioridad | Alta |
| Actor | Administrador |
| Descripción | El sistema debe permitir al administrador generar una invitación para el registro de un residente, asociándolo a una unidad residencial disponible y enviando al correo electrónico del residente un enlace para completar su registro. |
