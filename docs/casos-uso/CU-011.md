# CU-011 — Consultar estado de cuenta

> Transcripción de la ficha oficial: Tabla 55 del documento académico (*PROYECTO DE GRADO*, apartado 13.4.5 «Ficha de especificación de casos de uso»), leyenda «Tabla 55. CU-011 Consultar estado de cuenta». El documento original no se modifica. El texto se transcribe literalmente, incluidos los pasos 3 y 5 y la excepción 5a sin punto final, «informacion» sin tilde (excepción 5a) y las excepciones sin paso del actor (columna vacía en la ficha).

| Campo | Descripción |
|---|---|
| Identificador de Caso Uso | CU-011 |
| Nombre | Consultar estado de cuenta |
| Descripción | Permite al administrador consultar el estado de cuenta de un residente incluyendo las obligaciones económicas, pagos registrados, saldos pendientes y estado de morosidad. |
| Actores | Administrador |

## Secuencia normal

| Actor | Software |
|---|---|
| 1. Accede al módulo financiero. | 2. Muestra las opciones de consulta financiera. |
| 3. Selecciona la opción de estado de cuenta | 4. Muestra los residentes disponibles para consulta. |
| 5. Selecciona un residente | 6. Consulta la información financiera asociada al residente. |
| | 7. Muestra el estado de cuenta con las obligaciones, pagos, saldo y estado correspondiente. |
| 8. Revisa la información mostrada. | 9. El caso de uso termina. |

## Excepciones

| Actor | Software |
|---|---|
| 5a. Selecciona un residente sin informacion financiera disponible | 6a. Muestra un mensaje indicando que no existen datos financieros disponibles. |
| 5b. Solicita información de un residente inexistente. | 6b. Informa que el residente seleccionado no está disponible. |
| | 6c. Si ocurre un error durante la consulta, muestra un mensaje y no presenta información incompleta. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-004 Registrar pago manual; CU-008 Consultar historial de pagos; CU-012 Generar reportes financieros. |
| Precondición | El administrador debe tener una cuenta activa y el residente debe estar registrado en el sistema. |
| Post condición | El administrador visualiza el estado de cuenta actualizado del residente seleccionado. |
