# CU-015 — Gestionar información del residente

> Transcripción de la ficha oficial: Tabla 59 del documento académico (*PROYECTO DE GRADO*, apartado 13.4.5 «Ficha de especificación de casos de uso»), leyenda «Tabla 59. CU-015 Gestionar informacion del residente». El documento original no se modifica. El texto se transcribe literalmente, incluidos «4.Muestra» sin espacio, el doble espacio de «confirmación  necesaria», «7. Modifica la información o confirmar la eliminación» (infinitivo, sin punto final), el paso 1 sin punto final, «invalida» sin tilde y la minúscula inicial de «8b. impide». La leyenda de la tabla dice «Gestionar informacion del residente» (sin tilde), mientras que el campo Nombre dice «Gestionar información del residente»; este archivo usa el del campo Nombre en su título.

| Campo | Descripción |
|---|---|
| Identificador de Caso Uso | CU-015 |
| Nombre | Gestionar información del residente |
| Descripción | Permite al administrador actualizar la información registrada de un residente y eliminar el registro cuando corresponda de acuerdo con las condiciones establecidas en el sistema. |
| Actores | Administrador |

## Secuencia normal

| Actor | Software |
|---|---|
| 1. Accede al módulo de residentes | 2. Muestra el listado de residentes registrados. |
| 3. Selecciona un residente. | 4.Muestra la información disponible y las opciones de gestión. |
| 5. Selecciona la opción de actualizar o eliminar. | 6. Solicita la información o confirmación  necesaria para la operación seleccionada. |
| 7. Modifica la información o confirmar la eliminación | 8. Valida la operación solicitada. |
| | 9. Actualiza o elimina el registro según la operación realizada. |
| | 10. Actualiza el listado de residentes. |
| | 11. El caso de uso termina. |

## Excepciones

| Actor | Software |
|---|---|
| 7a. Ingresa información incompleta o invalida. | 8a. Muestra un mensaje indicando los datos que deben corregirse. |
| 7b. Intenta eliminar un residente que tiene información asociada que impide su eliminación. | 8b. impide la eliminación e informa la condición que debe resolverse. |
| 7c. Cancela la operación antes de confirmar. | 8c. No realiza cambios sobre la información registrada. |
| | 9a. Si ocurre un error durante la actualización o eliminación, informa al administrador y conserva la información anterior. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-003 Invitar residente; CU-006 Consultar residentes; CU-013 Gestionar unidades residenciales; CU-019 Activar cuenta de residente |
| Precondición | El administrador debe tener una cuenta activa y el residente debe estar registrado en el sistema. |
| Post condición | La información del residente queda actualizada o el registro queda eliminado cuando la operación es válida. |
