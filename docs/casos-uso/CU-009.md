# CU-009 — Registrar y consultar feedback

> Transcripción de la Tabla 53 del documento académico (*PROYECTO DE GRADO*). El documento original no se modifica. El texto se transcribe literalmente, incluidos «3a.Intenta», el paso 5 sin punto final y «No registrar el feedback». Las precisiones de diseño y las diferencias con la implementación están en [extensiones de diseño](../extensiones-diseno.md) (HU-009, "CU-009 frente a la implementación").

| Campo | Descripción |
|---|---|
| Identificador de Caso Uso | CU-009 |
| Nombre | Registrar y consultar feedback |
| Descripción | Permite al residente registrar un feedback relacionado con la comunidad o los servicios administrativos y consultar posteriormente el estado de los registros realizados. |
| Actores | Residente |

## Secuencia normal

| Actor | Software |
|---|---|
| 1. Accede a la funcionalidad de feedback desde su panel. | 2. Muestra el formulario de registro de feedback. |
| 3. Ingresa el asunto y el mensaje correspondiente. | 4. Muestra las categorías y niveles de urgencia disponibles. |
| 5. Selecciona la categoría y el nivel de urgencia | 6. Valida la información ingresada. |
| 7. Confirma el envío del feedback. | 8. Registra el feedback con su estado inicial. |
| | 9. Muestra un mensaje de confirmación. |
| 10. Accede posteriormente a sus registros de feedback. | 11. Muestra el listado y estado de los feedback registrados por el residente. |
| | 12. El caso de uso termina. |

## Excepciones

| Actor | Software |
|---|---|
| 3a.Intenta enviar el feedback sin completar el mensaje obligatorio. | 4a. Muestra un mensaje indicando que debe completar el campo requerido. |
| 3b. Ingresa un mensaje que supera la longitud permitida. | 4b. Informa que el mensaje excede el límite establecido. |
| 5a. No selecciona una categoría o nivel de urgencia requerido. | 6a. Solicita completar la información faltante. |
| 7a. Cancela el envío antes de confirmar. | 8a. No registrar el feedback y retorna al formulario o al panel anterior. |
| 10a. No existen registros de feedback asociados al residente. | 11a. Muestra un mensaje indicando que no existen feedback registrados. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-005 Gestionar feedback; CU-017 Gestionar notificaciones al residente |
| Precondición | El residente debe tener una cuenta activa y haber iniciado sesión en el sistema. |
| Post condición | El feedback queda registrado con su estado inicial y disponible para su posterior consulta y gestión. |
