# CU-016 — Restablecer contraseña

> **Caso de uso derivado.** El documento académico nombra CU-016 en la matriz de trazabilidad (módulo *Autenticación*, actor Residente), pero no incluye su descripción detallada. Esta descripción sigue la *Plantilla para descripción detallada de casos de uso* aprobada y aplica las decisiones registradas en [extensiones de diseño](../extensiones-diseno.md). No añade funcionalidades a HU-016 / RF-016. Solo para residentes.

| Campo | Descripción |
|---|---|
| Identificador de caso de uso | CU-016 |
| Nombre | Restablecer contraseña |
| Descripción | Permite al residente que no puede acceder solicitar un enlace por correo, validar su identidad con ese enlace y establecer una contraseña nueva. |
| Actores | Residente. |

## Secuencia normal

| Paso | Actor | Software |
|---|---|---|
| 1 | En la página de inicio de sesión selecciona "¿Olvidaste tu contraseña?". | |
| 2 | | Solicita el correo electrónico de la cuenta. |
| 3 | Ingresa su correo y confirma. | |
| 4 | | Muestra siempre el mismo mensaje: "Si la cuenta corresponde a un residente registrado, recibirás en tu correo un enlace para restablecer la contraseña. El enlace vence en 1 hora." |
| 5 | | Si el correo es de un residente activo: invalida cualquier enlace anterior, genera uno nuevo de un solo uso (guarda solo su resumen criptográfico), lo registra en la auditoría y lo envía por correo. |
| 6 | Abre el enlace recibido. | |
| 7 | | Retira el código del enlace de la barra de direcciones y verifica que el enlace siga vigente, sin usar y sin reemplazar, y que la cuenta siga activa. |
| 8 | | Muestra el formulario: nueva contraseña y confirmación. |
| 9 | Ingresa la nueva contraseña dos veces y confirma. | |
| 10 | | En una sola operación: guarda la contraseña protegida (Argon2id), marca el enlace como utilizado, cierra todas las sesiones abiertas del residente y lo registra en la auditoría. |
| 11 | | Confirma "Tu contraseña fue actualizada correctamente." y ofrece "Iniciar sesión". |
| 12 | | El caso de uso termina. El residente inicia sesión con la nueva contraseña (CU-007). |

## Excepciones

| Paso | Software |
|---|---|
| 3 | Si el correo está vacío o no tiene un formato válido, lo indica y no envía la solicitud. |
| 5 | Si el correo no corresponde a un residente activo (inexistente, administrador, pendiente de activación, deshabilitado o eliminado), no genera enlace ni envía correo; el mensaje del paso 4 es el mismo. |
| 5 | Si el residente ya pidió 3 enlaces en la última hora, no genera otro ni envía correo; el mensaje del paso 4 es el mismo. |
| 5 | Si el correo no se puede enviar, el fallo queda registrado en la auditoría; el residente puede solicitar un enlace nuevo. |
| 7 | Si el enlace no es válido, venció, ya fue utilizado o fue reemplazado por uno más reciente, lo informa y ofrece solicitar uno nuevo. |
| 9 | Si la contraseña no cumple las condiciones (12 a 128 caracteres, no solo espacios, distinta del correo) o la confirmación no coincide, indica el campo a corregir y no cambia nada. |
| 10 | Si el mismo enlace se usa a la vez en dos lugares, solo un cambio se completa; el otro informa que el enlace ya fue utilizado. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-007 Iniciar sesión como residente (precede y sigue). |
| Precondición | El residente tiene una cuenta activa (CU-019) y acceso a su correo. |
| Postcondición | La contraseña quedó cambiada, el enlace utilizado, todas las sesiones anteriores cerradas y todo registrado en la auditoría. No se crea sesión: el residente debe iniciar sesión de nuevo. |
