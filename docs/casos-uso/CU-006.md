# CU-006 — Consultar residentes

## Correspondencia con la implementación actual

> **Nota histórica (actualizada el 2026-10-10).** La descripción de esta sección se redactó como «caso de uso derivado» antes de localizar y transcribir la ficha oficial. Su nota original decía: «El documento académico nombra CU-006 en la matriz de trazabilidad (módulo *Gestión de residentes*, actor Administrador), pero no incluye su descripción detallada.» Esa afirmación ya no es vigente: el documento académico incluye la ficha de CU-006 en la Tabla 50, transcrita arriba (verificada en la auditoría de las fichas de casos de uso del 2026-10-10). La descripción se conserva como correspondencia con la implementación, no como parte de la ficha. Sigue la *Plantilla para descripción detallada de casos de uso* aprobada y aplica las decisiones registradas en [extensiones de diseño](../extensiones-diseno.md). No añade funcionalidades a HU-006 / RF-006: es **solo de consulta** (no crea, edita ni elimina residentes).

### Diferencias con la ficha oficial

- **Nombre y actor:** coinciden (Consultar residentes; Administrador).
- **Flujo principal:** coinciden el listado en tabla paginada, la búsqueda o el filtro y el orden. La implementación precisa la página de 10 residentes ordenada por nombre, las columnas, la búsqueda por nombre o documento, el filtro por estado, el cambio de tamaño de página y la nueva consulta al volver a la vista.
- **Excepciones:** 3a (sin residentes) y 5a (búsqueda sin coincidencias) corresponden a «Ausencia de resultados»; 5b (criterio inválido) a «Parámetros inválidos». La implementación añade la sesión o el rol no válidos y el error de consulta.
- **Precondición y postcondición:** la ficha exige una cuenta activa del administrador; la implementación, una sesión válida. La postcondición de la implementación precisa que no se modifica ningún dato.
- **Relaciones:** la ficha relaciona «CU-019 Gestionar información del residente»: el identificador es el de *Activar cuenta de residente* (Tabla 63) y el nombre el de CU-015 (Tabla 59). Es una discrepancia del documento académico y no se resuelve. La versión derivada relaciona ambos casos por separado (CU-019 Activar cuenta y CU-015 Gestionar información del residente), además de CU-002, CU-003, CU-013 y CU-018.

| Campo | Descripción |

| Descripción | Permite al administrador ver los residentes registrados con su documento, apartamento, teléfono, correo y estado, y buscarlos, filtrarlos, ordenarlos y recorrerlos por páginas. |
| Actores | Administrador. |

#### Secuencia normal

| Paso | Actor | Software |
|---|---|---|
| 1 | Accede al listado ("Residentes" en el panel de administración). | |
| 2 | | Comprueba la sesión y el rol (CU-018) y muestra "Cargando residentes…". |
| 3 | | Consulta los residentes registrados (rol residente, cuenta no eliminada, activa o inactiva, con residencia vigente). |
| 4 | | Muestra la primera página (10 residentes), ordenada por nombre: Nombre, Documento, Unidad (p. ej., `B1-TO2-APTO-104`), Teléfono, Correo y Estado (Activo o Inactivo), con el total ("Mostrando 1–10 de 42 residentes") y la paginación. |
| 5 | Busca por nombre o número de documento (o parte de él). | |
| 6 | | Al dejar de escribir, consulta y muestra desde la primera página los residentes cuyo nombre o documento contienen el texto. |
| 7 | Filtra por estado (Todos, Activo o Inactivo). | |
| 8 | | Consulta y muestra desde la primera página los residentes con ese estado, combinado con la búsqueda. |
| 9 | Ordena seleccionando el encabezado de una columna. | |
| 10 | | Consulta y muestra los residentes ordenados por esa columna (de nuevo, en sentido inverso); la unidad se ordena por bloque, torre y apartamento. |
| 11 | Navega entre páginas o cambia la cantidad por página. | |
| 12 | | Consulta y muestra la página pedida. |
| 13 | | El caso de uso termina. Al volver a la vista o a la pestaña, la lista se consulta de nuevo y muestra los datos actuales. |

#### Excepciones

| Paso | Software |
|---|---|
| 2–12 | **Sesión inexistente o no autorizada:** si no hay sesión válida (o terminó), lleva al inicio de sesión; si el usuario no es administrador, informa que no tiene permiso (403) y no muestra datos. |
| 5–12 | **Parámetros inválidos:** el sistema rechaza una página, una cantidad por página, un estado, un orden o una búsqueda fuera de los valores permitidos (no los aplica ni muestra datos con ellos). La interfaz solo envía valores permitidos; si la dirección de la página trae valores no válidos, usa los predeterminados. Si la página pedida ya no existe (hay menos residentes), muestra la última. |
| 4, 6, 8 | **Ausencia de resultados:** si no hay residentes registrados, informa "Aún no hay residentes registrados."; si ninguno coincide con la búsqueda o el filtro, informa "Ningún residente coincide con la búsqueda o el filtro." |
| 3–12 | **Error de consulta:** si no se puede cargar la lista, lo informa y ofrece "Reintentar", que vuelve a consultar. |
