# CU-012 — Generar reportes financieros

> Transcripción de la ficha oficial: Tabla 56 del documento académico (*PROYECTO DE GRADO*, apartado 13.4.5 «Ficha de especificación de casos de uso»), leyenda «Tabla 56. CU-012 Generar reportes financieros». El documento original no se modifica. El texto se transcribe literalmente, incluidas las excepciones sin paso del actor (columna vacía en la ficha) y, en «CU relacionados», «C-008 COnsultar historial de pagos» y la ausencia de punto final.

| Campo | Descripción |
|---|---|
| Identificador de Caso Uso | CU-012 |
| Nombre | Generar reportes financieros |
| Descripción | Permite al administrador generar y consultar reportes financieros relacionados con los pagos, saldos pendientes, historial de pagos y estados de cuenta de los residentes. |
| Actores | Administrador |

## Secuencia normal

| Actor | Software |
|---|---|
| 1. Accede al módulo de reportes financieros. | 2. Muestra las opciones disponibles para generar reportes. |
| 3. Selecciona el tipo de información que desea consultar. | 4. Solicita los criterios necesarios para generar el reporte. |
| 5. Define los criterios de consulta. | 6. Procesa la información financiera correspondiente. |
| | 7. Genera el reporte solicitado. |
| 8. Consulta la información presentada. | 9. El caso de uso termina. |

## Excepciones

| Actor | Software |
|---|---|
| 5a. No proporciona los criterios requeridos. | 6a. Solicita completar la información necesaria para generar el reporte. |
| 5b. Los criterios seleccionados no producen información. | 6b. Muestra un mensaje indicando que no existen datos para los criterios seleccionados. |
| | 6c. Si ocurre un error durante la generación, informa al administrador y no genera un reporte incompleto. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-004 Registrar pago manual; C-008 COnsultar historial de pagos; CU-011 Consultar estado de cuenta; CU-014 Consultar estado de cuenta propio |
| Precondición | El administrador debe tener una cuenta activa y debe existir información financiera registrada en el sistema. |
| Post condición | El sistema genera y presenta el reporte financiero correspondiente a los criterios seleccionados. |
