# CU-017 — Gestionar notificaciones al residente

> Transcripción de la ficha oficial: Tabla 61 del documento académico (*PROYECTO DE GRADO*, apartado 13.4.5 «Ficha de especificación de casos de uso»), leyenda «Tabla 61. CU-017 Gestionar notificaciones al residente». El documento original no se modifica. El texto se transcribe literalmente, incluidas las excepciones sin paso del actor (columna vacía en la ficha). El campo Actores de la ficha dice «Residente»; la matriz de trazabilidad (Tabla 39) indica el actor «Sistema». La diferencia se conserva sin corregir.

| Campo | Descripción |
|---|---|
| Identificador de Caso Uso | CU-017 |
| Nombre | Gestionar notificaciones al residente |
| Descripción | Permite gestionar el envío de notificaciones al residente relacionadas con eventos y procesos del sistema que requieren comunicación. |
| Actores | Residente |

## Secuencia normal

| Actor | Software |
|---|---|
| 1. Se produce un evento que requiere notificación al residente. | 2. Identifica el tipo de evento y el destinatario correspondiente. |
| | 3. Genera el contenido de la notificación. |
| | 4. Envía la notificación al residente mediante el mecanismo establecido. |
| 5. Recibe la notificación. | 6. Registra el resultado del envío cuando corresponda. |
| | 7. El caso de uso termina. |

## Excepciones

| Actor | Software |
|---|---|
| | 2a. No existe una dirección de contacto válida para el residente. El sistema informa que no puede realizar el envío. |
| | 3a. Se produce un error durante el procesamiento de la notificación. El sistema registra el error. |
| | 4a. El envío no puede completarse. El sistema informa el resultado y conserva el registro del evento para su seguimiento. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-004 Registrar pago manual; CU-005 Gestionar feedback; CU-010 Realizar pago electrónico |
| Precondición | Debe existir un evento del sistema que requiera comunicar información al residente y debe existir un medio de contacto registrado. |
| Post condición | La notificación queda enviada o registrada con el resultado correspondiente. |
