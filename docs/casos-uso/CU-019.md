# CU-019 — Activar cuenta del residente

> **Caso de uso derivado.** El documento académico nombra CU-019 en la matriz de trazabilidad (módulo *Gestion de usuarios*, actores Administrador / Residente), pero no incluye su descripción detallada. Esta descripción sigue la *Plantilla para descripción detallada de casos de uso* aprobada y aplica las decisiones registradas en [extensiones de diseño](../extensiones-diseno.md). La parte del administrador (crear y enviar la invitación) es CU-003. No añade funcionalidades a HU-019 / RF-019.

| Campo | Descripción |
|---|---|
| Identificador de caso de uso | CU-019 |
| Nombre | Activar cuenta del residente |
| Descripción | Permite al residente invitado abrir el enlace recibido por correo, completar sus datos, crear su contraseña y activar su cuenta, que queda asociada al apartamento asignado por el administrador. |
| Actores | Residente (la invitación la crea el Administrador en CU-003). |

## Secuencia normal

| Paso | Actor | Software |
|---|---|---|
| 1 | Abre el enlace de invitación recibido por correo. | |
| 2 | | Retira el código del enlace de la barra de direcciones y verifica la invitación: que exista, esté pendiente y vigente, y que la cuenta esté pendiente de activación. |
| 3 | | Muestra el nombre, el correo, el apartamento y la fecha de vencimiento (no editables) y el formulario: documento, teléfono (opcional), contraseña y confirmación. |
| 4 | Completa los datos y confirma. | |
| 5 | | Valida los datos y que el documento no esté registrado. |
| 6 | | En una sola operación: guarda la contraseña protegida (Argon2id), activa la cuenta, la asocia al apartamento de la invitación, marca la invitación como utilizada y lo registra en la auditoría. |
| 7 | | Informa que la cuenta está activa. |
| 8 | | El caso de uso termina. El inicio de sesión del residente corresponde a HU-007. |

## Excepciones

| Paso | Software |
|---|---|
| 2 | Si el enlace no es válido (inexistente, alterado, reemplazado por un reenvío o de una cuenta que ya no está pendiente), informa que el enlace no es válido. |
| 2 | Si la invitación venció, la marca como vencida e informa que ya no se encuentra vigente; la administración puede enviar una nueva (CU-003). |
| 2 | Si la invitación ya fue utilizada, informa que el enlace ya fue utilizado. |
| 5 | Si falta un dato o es inválido (documento, teléfono, contraseña o confirmación), indica los campos a corregir y no activa nada. |
| 5 | Si el documento ya está registrado, lo informa y no activa nada; el residente puede corregirlo y volver a intentar. |
| 6 | Si el apartamento ya no está disponible, lo informa y no activa nada. |
| 6 | Si el mismo enlace se usa a la vez en dos lugares, solo una activación se completa; la otra informa que el enlace ya fue utilizado. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-003 Invitar residente (precede). CU-007 Iniciar sesión como residente (sigue; pendiente). |
| Precondición | Existe una invitación pendiente y vigente creada en CU-003, y el residente tiene el enlace. |
| Postcondición | El usuario residente está activo con su contraseña, existe su residencia en el apartamento, la invitación está utilizada y todo queda en la auditoría. No se crea sesión. |
