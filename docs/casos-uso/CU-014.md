# CU-014 — Consultar estado de cuenta propio

> Transcripción de la ficha oficial: Tabla 58 del documento académico (*PROYECTO DE GRADO*, apartado 13.4.5 «Ficha de especificación de casos de uso»), leyenda «Tabla 58. CU-014 Consultar estado de cuenta propio». El documento original no se modifica. El texto se transcribe literalmente, incluidos el actor «Residente.» con punto final y la minúscula inicial de «4b. si ocurre».

| Campo | Descripción |
|---|---|
| Identificador de Caso Uso | CU-014 |
| Nombre | Consultar estado de cuenta propio |
| Descripción | Permite al residente consultar el estado de cuenta, incluyendo obligaciones pendientes, pagos registrados y saldo correspondiente. |
| Actores | Residente. |

## Secuencia normal

| Actor | Software |
|---|---|
| 1. Accede al módulo de estado de cuenta. | 2. Consulta la información financiera asociada al residente autenticado. |
| 3. Solicita consultar su estado de cuenta. | 4. Muestra las obligaciones, pagos registrados y saldo correspondiente. |
| 5. Revisa la información presentada. | 6. Mantiene disponible la información para su consulta. |
| | 7. El caso de uso termina. |

## Excepciones

| Actor | Software |
|---|---|
| 3a. No existen obligaciones o movimientos registrados. | 4a. Muestra un mensaje indicando que no existen movimientos u obligaciones disponibles. |
| | 4b. si ocurre un error durante la consulta, informa al residente que no fue posible obtener la información. |

## Relaciones

| Campo | Descripción |
|---|---|
| CU relacionados | CU-008 Consultar historial de pagos; CU-010 Realizar pago electrónico; CU-011 Consultar estado de cuenta |
| Precondición | El residente debe tener una cuenta activa y haber iniciado sesión en el sistema. |
| Post condición | El residente visualiza el estado de su cuenta con la información financiera disponible. |
