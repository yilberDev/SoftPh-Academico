# HU-007 — Inicio de sesión del residente

|---|---|

| Prioridad en el negocio | Alta |

| Rol del usuario (Cómo) | Residente, quiero iniciar sesión en el sistema |
| Deseo (Qué) | Iniciar sesión en el sistema utilizando mi correo electrónico y contraseña. |
| Propósito (Para) | Acceder a las funcionalidades disponibles para el residente. |
| Observaciones | El sistema debe validar las credenciales del residente y permitir el acceso únicamente cuando la información proporcionada sea válida. |

## Criterios de aceptación

| No. | Contexto | No. | Evento |
|---|---|---|---|
| 1 | Ingreso exitoso | 1 | Cuando el residente ingrese correctamente su correo electrónico y contraseña |
| | | 2 | El sistema permitirá el ingreso y redirigirá al residente al panel principal. |
| 2 | Ingreso fallido | 1 | Cuando el residente ingrese un correo electrónico o contraseña incorrectos. |
| | | 2 | El sistema no permitirá el ingreso al sistema. |
| | | 3 | El sistema mostrará una alerta informando que las credenciales ingresadas no son válidas. |
| 3 | Restablecer contraseña | 1 | Cuando el residente requiera restablecer su contraseña. |
| | | 2 | El sistema deberá permitir iniciar el proceso correspondiente para recuperar el acceso. |

## Estado de cumplimiento

HU-007 reutiliza el login único de HU-002 (mismo endpoint, sesiones, control de intentos y auditoría): el backend determina el rol. Ver [extensiones de diseño](../extensiones-diseno.md) (HU-007).

| Criterio | Estado | Detalle |
|---|---|---|
| 1 | Cumplido | Un residente activo (cuenta activada en HU-019) ingresa en `/login` con su correo y contraseña; el backend crea la sesión y el residente llega a su panel principal `/resident`. El destino depende solo del rol que devuelve el backend. |
| 2 | Cumplido | Correo inexistente, contraseña incorrecta o cuenta no activa (pendiente de activación, deshabilitada o eliminada): no hay ingreso y se muestra la misma alerta genérica "Correo electrónico o contraseña no válidos.". Tras 5 intentos fallidos en 15 minutos el acceso con ese correo se bloquea 15 minutos (igual que en HU-002). |
| 3 | **Parcial — dependencia de HU-016** | **Cumplido:** el enlace "¿Olvidaste tu contraseña?" del login lleva a `/forgot-password`, el punto de inicio de la recuperación. **Pendiente de HU-016:** el proceso de recuperación (solicitud, enlace por correo y nueva contraseña). Mientras tanto la página indica que la recuperación en línea aún no está disponible y que el residente se comunique con la administración. |

**HU-007 no se considera completamente satisfecha** hasta que HU-016 implemente el proceso de recuperación (criterio 3.2).
