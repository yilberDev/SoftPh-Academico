## Criterios de Aceptación:

| No. | Contexto | No. | Evento |
|---|---|---|---|
| 1 | Consulta del estado de cuenta | 1 | El administrador debe poder seleccionar un residente y consultar su estado de cuenta. |
| | | 2 | El sistema debe mostrar las obligaciones y pagos asociados al residente. |
| 2 | Visualización de saldos. | 1 | El sistema debe mostrar el valor total pendiente de pago del residente. |
| | | 2 | El sistema debe mostrar los pagos registrados que hayan sido aplicados a la cuenta. |
| 3 | Identificación de morosidad | 1 | Cuando un residente tenga obligaciones pendientes después de la fecha establecida para su pago, el sistema debe identificar su cuenta como pendiente o en mora, según corresponda. |
| | | 2 | El administrador debe poder identificar los residentes que presentan obligaciones pendientes. |
| 4 | Actualización de la información. | 1 | Cuando se registre un nuevo pago asociado al residente, el estado de cuenta debe actualizarse con la nueva información. |
| | | 2 | El sistema debe reflejar el estado actualizado de la cuenta al consultar nuevamente la información. |
