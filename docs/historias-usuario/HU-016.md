# HU-016 — Restablecimiento de contraseña del residente

> Transcripción de la Tabla 16 del documento académico (*PROYECTO DE GRADO*). El documento original no se modifica.

| Campo | Valor |
|---|---|
| Número | HU-016 |
| Nombre de la historia | Restablecimiento de contraseña del residente |
| Prioridad en el negocio | Alta |
| Programador responsable | Yilber Sanchez |
| Rol del usuario (Cómo) | Residente, quiero restablecer mi contraseña cuando no pueda acceder al sistema. |
| Deseo (Qué) | Recuperar el acceso a mi cuenta mediante un proceso seguro de restablecimiento de contraseña. |
| Propósito (Para) | Recuperar el acceso al sistema y continuar utilizando las funcionalidades disponibles para el residente. |
| Observaciones | El proceso de restablecimiento debe realizarse de manera segura y validar la identidad del usuario antes de permitir el cambio de contraseña. |

## Criterios de aceptación

| No. | Contexto | No. | Evento |
|---|---|---|---|
| 1 | Acceso al restablecimiento de contraseña. | 1 | El residente debe disponer de una opción para iniciar el proceso de restablecimiento de contraseña desde la pantalla de inicio de sesión |
| | | 2 | El sistema debe solicitar la información necesaria para identificar la cuenta del residente. |
| 2 | Validación de la cuenta. | 1 | Cuando el residente proporcione una cuenta registrada en el sistema. |
| | | 2 | El sistema debe permitir continuar con el proceso de restablecimiento. |
| 3 | Cuenta no encontrada. | 1 | Cuando el residente proporcione información que no corresponda a una cuenta registrada. |
| | | 2 | El sistema no debe permitir continuar con el restablecimiento e informará que la información proporcionada no corresponde a una cuenta válida. |
| 4 | Cambio de contraseña. | 1 | Cuando el residente complete correctamente el proceso de validación. |
| | | 2 | El sistema debe permitir establecer una nueva contraseña que cumpla con las condiciones de seguridad definidas. |
| 5 | Confirmación del restablecimiento. | 1 | Cuando la nueva contraseña sea registrada correctamente. |
| | | 2 | El sistema debe confirmar que la contraseña fue actualizada y permitir al residente iniciar sesión nuevamente. |

## Estado de cumplimiento

HU-016 es **exclusivamente para residentes** (no hay recuperación para el administrador). Ver [extensiones de diseño](../extensiones-diseno.md) (HU-016).

| Criterio | Estado | Detalle |
|---|---|---|
| 1 | Cumplido | El login (HU-007) enlaza "¿Olvidaste tu contraseña?" a `/forgot-password`, que solicita el correo electrónico de la cuenta. |
| 2 | Cumplido | Si el correo pertenece a un residente activo, se genera un enlace único (1 hora de vigencia) y se envía a ese correo: `/reset-password#token=…`. Al abrirlo, el sistema valida el enlace y permite continuar. |
| 3 | Cumplido, con la interpretación de seguridad aprobada | Si el correo no corresponde a una cuenta válida de residente (inexistente, administrador, pendiente de activación, deshabilitada o eliminada), no se genera enlace ni se envía correo, así que **no es posible continuar**. Para no revelar qué correos están registrados (enumeración de cuentas), el mensaje es el mismo para cualquier correo: "Si la cuenta corresponde a un residente registrado, recibirás…". Así el sistema informa la condición sin confirmar ni negar la existencia de la cuenta. |
| 4 | Cumplido | La nueva contraseña cumple la política de HU-001 (12 a 128 caracteres, no solo espacios, distinta del correo, confirmación) y se guarda con Argon2id. |
| 5 | Cumplido | Se confirma "Tu contraseña fue actualizada correctamente." con el botón "Iniciar sesión". El enlace queda utilizado, se cierran todas las sesiones abiertas del residente y la contraseña anterior deja de funcionar; el residente entra con la nueva (HU-007). |
