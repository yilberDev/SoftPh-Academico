## Criterios de Aceptación:

| No. | Contexto | No. | Evento |
|---|---|---|---|
| 1 | Consulta del estado de cuenta. | 1 | El residente debe poder acceder desde su panel a la información de su estado de cuenta. |
| | | 2 | El sistema debe mostrar las obligaciones y pagos asociados a su cuenta. |
| 2 | Visualización de saldos | 1 | El sistema debe mostrar el valor total de las obligaciones pendientes del residente. |
| | | 2 | El sistema debe mostrar los pagos registrados que hayan sido aplicados a su cuenta. |
| 3 | Identificación de obligaciones pendientes. | 1 | Cuando el residente tenga obligaciones pendientes, el sistema debe mostrar cuáles se encuentran pendientes de pago. |
| | | 2 | El sistema debe permitir identificar el valor asociado a cada obligación pendiente. |
| 4 | Actualización de la información. | 1 | Cuando se registre y procese correctamente un nuevo pago, el estado de cuenta del residente debe actualizarse. |
| | | 2 | El nuevo saldo y estado de la cuenta deben reflejarse al consultar nuevamente la información. |
| 5 | Acceso a la información. | 1 | El residente debe poder consultar su información financiera sin acceder a la información de otros residentes. |
| | | 2 | El sistema debe mostrar un mensaje adecuado cuando no existan obligaciones o movimientos registrados. |
