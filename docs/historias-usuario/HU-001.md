# HU-001 — Registro de administrador

> Transcripción de la Tabla 1 del documento académico (*PROYECTO DE GRADO*). El documento original no se modifica.

| Campo | Valor |
|---|---|
| Número | HU-001 |
| Nombre de la historia | Registro de administrador |
| Prioridad en el negocio | Alta |
| Programador responsable | Yilber Sanchez |
| Rol del usuario (Cómo) | Administrador, quiero registrarme en el sistema proporcionando la información requerida para crear mi cuenta de acceso. |
| Deseo (Qué) | Registrarme en el sistema con mi información personal, de contacto y de acceso. |
| Propósito (Para) | Acceder al software y gestionar las operaciones administrativas de la Urbanización San Joaquín. |
| Observaciones | Es esencial que el proceso de registro esté protegido para garantizar la seguridad de los datos personales y de las credenciales de acceso. |

## Criterios de aceptación

| No. | Contexto | Evento |
|---|---|---|
| 1 | Registro exitoso | Cuando el administrador complete el formulario de registro con todos los datos requeridos y estos sean válidos, entonces el sistema permitirá crear la cuenta del administrador y mostrará una confirmación del registro exitoso. |
| 2 | Registro fallido | Cuando el administrador intente registrarse utilizando un correo electrónico que ya se encuentre registrado, entonces el sistema no permitirá crear la cuenta. |
| 3 | Validación de datos | Cuando el administrador no complete uno o más campos obligatorios o introduzca información que no cumpla con las validaciones establecidas, entonces el sistema no permitirá completar el registro y mostrará las validaciones correspondientes. |
